# 编辑与排版

用工具栏和菜单整理文字，也可以直接输入 Markdown 标记。

## 01 切换显示方式

**即时渲染模式**显示排版后的内容，适合日常写作。**源码模式**显示 Markdown 原文，适合调整标记、链接和代码。

点击工具栏中的模式切换按钮，或按 `Ctrl + /`。空白文档也可以切换；代码文件默认以源码模式打开。

对空格、缩进有严格要求时，建议使用源码模式。两种模式的撤销历史分别记录，切换后不能通过撤销回到另一种模式的编辑步骤。

## 02 常用格式

| 内容 | 输入示例 | 快捷操作 |
| --- | --- | --- |
| 一级标题 | `# 标题` | `Ctrl + 1` |
| 加粗 | `**重点**` | `Ctrl + B` |
| 斜体 | `*强调*` | `Ctrl + I` |
| 链接 | `[文字](地址)` | `Ctrl + K` |
| 任务列表 | `- [ ] 待办事项` | 段落 → 任务列表 |
| 引用 | `> 引用内容` | 段落 → 引用 |

引用、代码块和列表按钮会显示当前位置的格式；再次点击，可以取消该格式。

## 03 使用右键菜单

右键菜单会随点击对象变化：选中文字可复制、调整格式或建立便签；右键链接可编辑地址；右键图片可调整或另存图片；右键代码块可设置“代码语言…”。

要增删表格行列，先选中表格或单元格区域，再点击右键。Markdown 表格的首行是表头。

在正文中移除图片或链接，只会移除引用，不会删除原文件。

## 04 用 Mermaid 绘制流程图

插入代码块，将语言设为 `mermaid`，输入下面的示例：

```mermaid
flowchart LR
  A[收集资料] --> B[整理笔记]
  B --> C[完成初稿]
```

点击“显示图形”查看流程图，点击“编辑源码”继续修改。绘图不需要联网。

**图太小时，点击图形即可在新窗口中放大查看。** 在新窗口中还能缩放，或右键“保存为图片”导出 PNG。

如果没有生成图形，请检查语法；复杂图表可以拆成几张。

## 05 调整阅读空间

在“视图”菜单中，可以显示或隐藏侧栏、调整编辑区大小，或进入全屏。只调整编辑区大小时，菜单和侧栏不会一起放大。

字体、正文宽度和背景的设置方法，见[把 Arkdown 调整得顺手](<09-把 Arkdown 调整得顺手.md>)。
