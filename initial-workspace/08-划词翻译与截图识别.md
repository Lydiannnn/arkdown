# 划词翻译与截图识别

翻译选中的文字，或从屏幕截图中提取文字。

## 01 连接翻译模型

打开“文件 → 偏好设置 → 大模型设置 → 管理大模型”。选择供应商，输入对应的 API Key，选择模型并连接。

已经连接过模型就不必重复添加。为“划词翻译配置”或“截图翻译配置”选择要使用的模型和目标语言即可。

翻译需要联网，相关文字会发送给所选模型服务。额度和费用以该服务商的说明为准。

## 02 翻译选中的文字

选中正文，点击出现的翻译按钮。在翻译浮层或右侧栏查看、复制结果；之前的结果可在“翻译记录”中查找。

查看、复制译文不会自动改写正文。需要替换时，核对后自行编辑并保存。

## 03 截图提取文字

1. 选择“工具 → 截图翻译”，或按 `Ctrl + Shift + Q`。
2. 框选文字所在区域，等待识别。
3. 核对识别出的文字，再进行翻译。

文字识别在本机完成；即使没有连接翻译模型，也可以先提取文字。翻译时只发送识别出的文字。

尽量选择清晰、字号较大的文字。需要更高精度时，可在“截图OCR识别”设置中按提示下载识别模型。

## 04 悬浮翻译窗（实验功能）

打开“工具 → 悬浮翻译窗（实验功能）”，首次使用时按提示安装组件。

在大模型设置中为“悬浮翻译窗”选择模型和目标语言；也可以在工具面板选择百度快译，填写对应密钥。

拖动准星移动取景框，拖动边缘调整大小。工具打开后，可使用：

| 操作 | 快捷键 |
| --- | --- |
| 翻译一次 | `Ctrl + Shift + A` |
| 开关自动翻译 | `Ctrl + Alt + T` |
| 清除译文 | `Ctrl + Shift + D` |

这是实验功能，建议先从小范围开始使用。关闭工具会停止本次识别和翻译。

## 05 遇到问题

| 提示 | 可以怎么做 |
| --- | --- |
| 未配置模型 | 回到大模型设置，为相应翻译功能选择模型。 |
| 认证失败 | 检查 API Key 或登录状态。 |
| 模型不存在或配置无效 | 重新选择可用模型，按服务商说明检查设置。 |
| 超时或请求过多 | 检查网络，稍后重试。 |
| 余额或额度不足 | 到模型服务商的网站查看账号额度。 |
| 组件下载失败 | 检查网络后，按提示重试下载。 |
