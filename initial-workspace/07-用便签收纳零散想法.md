# 用便签收纳零散想法

把待办和片段放进便签盒子，需要时打开为桌面便签。

## 01 创建或导入便签

1. **打开便签盒子**
   点击编辑工具栏中的“便签盒子”。
2. **创建一张便签**
   选择“创建新便签”，确认名称，再打开卡片编辑。
3. **也可以从现有内容开始**
   选中正文后右键“建立便签”，或把 .md、.markdown、.txt 文件拖进便签盒子。

**创建的是独立副本**

从正文建立便签不移动或改写原文档。导入 Markdown 时，会把引用的本地资源复制到便签资源目录，源文件和源资源保持不变。

## 02 编辑与实时保存

便签会在停止输入后实时保存；请留意“实时保存中...”和“已保存”。关闭前等待保存完成。便签的实时保存只作用于这张便签，不会同步回创建它的原文档。

当前便签提供 Mica、Acrylic 和颜色材质。在偏好设置中选择新便签的默认材质和颜色；已有便签保持原样。

## 03 打开桌面便签与置顶

| 操作 | 效果 |
| --- | --- |
| 点击便签卡片 | 切换这张便签的桌面展示状态。 |
| 置顶便签 / 取消置顶 | 使窗口始终位于其他窗口上方；不会锁定编辑。 |
| 关闭便签 | 关闭桌面展示，保留便签内容。 |
| 归档 | 收纳暂时不用的便签；需要编辑时先恢复。 |

便签卡片右键提供“改变颜色”“材质”“设置背景...”“重命名”“归档”和“删除”。当前便签功能由 Arknote 配合提供。可在“文件 → 偏好设置 → Arknote”配置开机启动、默认材质和颜色；桌面创建入口位于“右键菜单”设置。

## 04 搜索、归档与容量

在便签盒子按 `Ctrl + F` 搜索活跃便签；切换到归档后，单独搜索归档内容。活跃搜索不会包含归档。

活跃便签达到 35 个时，先归档暂时不用的内容，再创建新便签。删除与归档不同，长期留存建议先备份。

**开机启动与移动程序**

启用开机启动后，移动程序文件夹会让原有启动路径失效。移动后请检查并重新设置开机启动。
