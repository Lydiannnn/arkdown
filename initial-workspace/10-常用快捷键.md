# 常用快捷键

把高频操作留在手边。以下为 Windows 版 Arkdown 的默认快捷键；自定义后以“编辑 → 快捷键”中的设置为准。

## 01 文件与窗口

| 操作 | 快捷键 |
| --- | --- |
| 新建文档 | `Ctrl + N` |
| 新建窗口 | `Ctrl + Shift + N` |
| 打开文档 | `Ctrl + O` |
| 打开文件夹 | `Ctrl + Shift + O` |
| 保存 | `Ctrl + S` |
| 另存为 | `Ctrl + Shift + S` |
| 打印 | `Ctrl + P` |
| 关闭窗口 | `Ctrl + W` |

## 02 编辑与视图

| 操作 | 快捷键 |
| --- | --- |
| 在文档中搜索 | `Ctrl + F` |
| 在文件夹中搜索 | `Ctrl + Shift + F` |
| 显示或隐藏大纲 | `Ctrl + Shift + E` |
| 加粗 / 斜体 | `Ctrl + B` / `Ctrl + I` |
| 插入链接 | `Ctrl + K` |
| 一级至六级标题 | `Ctrl + 1` 至 `Ctrl + 6` |
| 正文 | `Ctrl + `` |
| 切换源码模式 | `Ctrl + /` |
| 显示或隐藏侧栏 | `Ctrl + Shift + L` |
| 截图翻译 | `Ctrl + Shift + Q` |

**自定义快捷键**

打开“编辑 → 快捷键”，点击“修改”后按下组合键，修改后立即保存。支持清除和恢复默认；通用编辑、格式与导航键固定显示。按 Esc 取消录入。

**快捷键的作用取决于当前窗口**

例如便签盒子中的 Ctrl + F 搜索便签；文档编辑器中的 Ctrl + F 查找当前文档。本说明网页的搜索可按 Ctrl + K 打开。
