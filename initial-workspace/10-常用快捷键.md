# 常用快捷键

以下为 Windows 版 Arkdown 的默认快捷键。自定义后，以“编辑 → 快捷键”中的设置为准。

## 01 文件与窗口

| 操作 | 快捷键 |
| --- | --- |
| 新建文档 | `Ctrl + N` |
| 新建窗口 | `Ctrl + Shift + N` |
| 打开文档 | `Ctrl + O` |
| 打开文件夹 | `Ctrl + Shift + O` |
| 保存 | `Ctrl + S` |
| 另存为 | `Ctrl + Shift + S` |
| 打印 | `Ctrl + P` |
| 关闭窗口 | `Ctrl + W` |

## 02 搜索、视图与导航

| 操作 | 快捷键 |
| --- | --- |
| 在文档中搜索 | `Ctrl + F` |
| 在文件夹中搜索 | `Ctrl + Shift + F` |
| 显示或隐藏大纲 | `Ctrl + Shift + E` |
| 切换源码模式 | `Ctrl + /` |
| 显示或隐藏侧边栏 | `Ctrl + Shift + L` |
| 实际大小 | `Ctrl + 0` |
| 整体放大 / 缩小 | `Ctrl + +` / `Ctrl + -` |
| 全屏 | `F11` |
| 打开正文链接 | `Ctrl` + 单击 |

## 03 编辑与格式

| 操作 | 快捷键 |
| --- | --- |
| 撤销 / 重做 | `Ctrl + Z` / `Ctrl + Y` |
| 剪切 / 复制 / 粘贴 | `Ctrl + X` / `Ctrl + C` / `Ctrl + V` |
| 全选 | `Ctrl + A` |
| 加粗 / 斜体 | `Ctrl + B` / `Ctrl + I` |
| 插入链接 | `Ctrl + K` |
| 一级至六级标题 | `Ctrl + 1` 至 `Ctrl + 6` |
| 正文 | `` Ctrl + ` `` |
| 行内代码（渲染模式） | `Ctrl + E` |
| 引用（渲染模式） | `Ctrl + Shift + B` |
| 代码块（渲染模式） | `Ctrl + Alt + C` |
| 有序 / 无序列表（渲染模式） | `Ctrl + Alt + 7` / `Ctrl + Alt + 8` |
| 增加 / 减少缩进，或切换表格单元格 | `Ctrl + ]` / `Ctrl + [` |
| 退出代码块或表格（渲染模式） | `Ctrl + Enter` |

## 04 翻译工具

| 操作 | 快捷键 |
| --- | --- |
| 截图翻译 | `Ctrl + Shift + Q` |
| 悬浮翻译一次 | `Ctrl + Shift + A` |
| 悬浮自动翻译开关 | `Ctrl + Alt + T` |
| 清除悬浮译文 | `Ctrl + Shift + D` |

悬浮翻译的快捷键仅在该工具打开时生效；入口为“工具 → 悬浮翻译窗（实验功能）”。

## 05 修改快捷键

打开“编辑 → 快捷键”，点击“修改”后按下新的组合键。按 `Esc` 取消，也可以按界面提示恢复默认。

先点击要操作的区域，再使用快捷键。例如，在便签盒子按 `Ctrl + F` 搜索便签；在正文中按它，则搜索当前文档。
