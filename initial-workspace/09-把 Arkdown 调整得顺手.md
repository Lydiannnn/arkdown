# 把 Arkdown 调整得顺手

设置字体、版面、主题颜色与工具选项，让阅读和写作适合自己的习惯。

## 01 主题颜色与字体

打开“文件 → 偏好设置”。“主题 → 主题颜色”提供预设和自定义颜色；编辑器主题菜单当前提供“简约”。主题颜色设置不等于新增一套编辑器主题。

在“编辑器 → 字体选择”分别设置标题中文、标题英文、正文中文、正文英文字体。列表来自本机已安装字体，字体变化只影响显示，不修改 Markdown 内容。

本说明网页右上角的深浅色切换只改变说明书外观，不会修改软件设置。

## 02 为编辑器添加背景

1. **打开背景设置**
   主题 → 设置背景...；也可以在偏好设置的“设置背景”下点击“打开设置窗口”。
2. **选择图片并预览**
   点击“添加图片”，再调整图片不透明度、图片对齐方式和遮罩类型。按需修改遮罩区域不透明度、过渡速度与强度。
3. **应用或取消**
   点击“应用”保留设置，点击“取消”放弃这次背景调整。需要清除时使用“移除背景”。

## 03 正文宽度、边距与换行

| 设置 | 作用 |
| --- | --- |
| 最小边距：30～150 px | 控制正文左右各自保留的最小距离。 |
| 正文宽度：600～1200 px | 控制正文最大宽度；窗口变窄时正文随之收窄。 |
| 保留单个换行 | 开启后，源码中的真实换行会在即时渲染中显示。关闭则按标准 Markdown 合并段落中的单换行。 |
| 拼写检查 | 在偏好设置或“编辑 → 拼写检查”开启或关闭。 |

**新版设置即时生效**

偏好设置中的有效修改会即时保存，完成后点击“关闭”或返回箭头。关闭页面不是撤销修改。背景设置窗口则需单独点击“应用”。

## 04 使用默认浏览器搜索

先选中文字，再从右键菜单选择“使用默认浏览器搜索”。在“浏览器搜索”设置中可以选择百度、Bing、Google，或含 `{query}` 的自定义 HTTPS 搜索地址。最新包的默认项为百度。

**默认浏览器与默认搜索引擎是两回事**

Arkdown 可以打开 Windows 默认浏览器，但不能读取浏览器内部的默认搜索引擎。希望一致时，请手动选择相同提供商。

## 05 Windows 右键与默认程序

在偏好设置的“右键菜单”中，分别开关：md/txt 文档上的“使用Arkdown打开”、桌面右键中的“创建新便签”、右键“新建”中的 Markdown 文档。

“md/txt默认程序”用于进入 Windows 默认应用设置。按系统提示，将 .md 与 .txt 都设为 Arkdown，再回到软件检查状态。只设置一种类型时，不会显示为全部完成。

**默认应用由 Windows 确认**

启动时遇到默认程序提示，可以选择“稍后”，以后再从偏好设置进入。移动免安装程序后，应重新核对这些路径相关的设置。

## 06 按需管理可选组件

“文档转换”用于安装、查看和删除转换组件，支持 PDF、PPTX、XLSX、EPUB 的 Markdown 预览。“截图OCR识别”用于下载或管理识别模型。请按界面状态等待安装完成。

删除转换组件后，相应转换功能会不可用，但源文档不会删除。程序随附的本地归档与用户目录中已安装组件是不同的文件。
