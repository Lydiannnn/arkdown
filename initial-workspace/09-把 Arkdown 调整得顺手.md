# 把 Arkdown 调整得顺手

大部分设置都在“文件 → 偏好设置”中，可以按自己的阅读和写作习惯调整。

## 01 颜色与字体

在“主题 → 主题颜色”中选择喜欢的颜色。

在偏好设置的“编辑器 → 字体选择”中，分别设置标题和正文的中英文字体。可选字体来自本机，修改字体只影响显示。

## 02 设置背景

打开“主题 → 设置背景…”，点击“添加图片”，调整透明度、位置和遮罩后，点击“应用”。

不想保留这次调整时，点击“取消”；不再需要背景时，点击“移除背景”。

## 03 正文宽度与换行

| 设置 | 作用 |
| --- | --- |
| 最小边距 | 调整正文与窗口左右边缘的距离。 |
| 正文宽度 | 限制每行显示的宽度，避免文字铺得太满。 |
| 保留单个换行 | 按原文中的换行显示；关闭后，同一段内的单个换行可能合并。 |
| 拼写检查 | 开启或关闭拼写提示。 |

偏好设置通常即时保存；背景窗口需要单独点击“应用”。看到错误提示时，先按提示处理，再关闭设置。

## 04 用浏览器搜索文字

选中文字，右键“使用默认浏览器搜索”，即可在浏览器中搜索。

搜索引擎在 Arkdown 的“浏览器搜索”设置中选择，不随浏览器内部的搜索设置变化。

## 05 默认程序和 Windows 右键菜单

在“右键菜单”设置中，可以添加“使用Arkdown打开”“创建新便签”和新建 Markdown 文档等入口。

勾选“md/txt默认程序”，可将 Arkdown 设为 Markdown 和 TXT 的默认打开程序。如果没有成功，按提示到 Windows 默认应用设置中确认。

## 06 按需下载组件

部分功能首次使用时，需要下载一个组件。按界面提示安装即可，之后可以重复使用。

| 功能 | 使用的组件 |
| --- | --- |
| 打开和导出 Word 文档 | Pandoc |
| 转换 PDF、PPTX、XLSX、EPUB | MarkItDown |
| 更高精度的截图文字识别 | OCR 识别模型 |
| 悬浮翻译窗 | 悬浮翻译组件 |
| 通过 ChatGPT 登录使用模型 | Codex CLI |

组件通过腾讯云下载，首次安装需要联网。直接用 API Key 连接其他大模型供应商时，不需要 Codex CLI。
