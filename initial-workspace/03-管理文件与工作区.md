# 管理文件与工作区

工作区就是你选择的一个本地文件夹。文档仍是普通文件，可以用 Windows 文件夹管理，也可以在 Arkdown 左侧浏览。

## 01 打开文档和工作区

| 想做什么 | 操作 |
| --- | --- |
| 打开文档 | “文件 → 打开文档…”或 `Ctrl + O`。 |
| 选择工作区 | 点击左上角工作区按钮，或按 `Ctrl + Shift + O`。 |
| 新开一个窗口 | “文件 → 新建窗口”或 `Ctrl + Shift + N`。 |
| 打开最近的文档 | “文件 → 最近编辑的文档…”。 |

也可以把文档或它的 Windows 快捷方式拖到窗口空白处打开。

点击工作区按钮后，选择窗口会定位到当前工作区。首次出现引导时，点击“好的”即可选择文件夹。

## 02 整理文件

在左侧文件树中右键，可以新建文档、新建文件夹、重命名或创建文档副本。新文档名称没有扩展名时，会自动补上 `.md`。

选择“移到回收站”会处理磁盘上的实际文件。只是关闭文档窗口，不会删除文件。

## 03 把文件复制到桌面或其他文件夹

先保存文档，再把鼠标放到左侧文件行上，从“拖出文件”按钮开始拖动：

- 直接拖动：复制文件，原文件保留。
- 按住 `Alt` 或 `Ctrl + Shift` 拖动：创建快捷方式。

目标文件夹已有同名文件时，按 Windows 提示处理。在原文件夹内复制一份，建议右键选择“创建副本”。

## 04 查找内容

| 想找什么 | 操作 |
| --- | --- |
| 当前文档中的文字 | 按 `Ctrl + F`。 |
| 工作区中的内容 | 按 `Ctrl + Shift + F`；需要搜索子文件夹时，按提示继续。 |
| 文档的某个章节 | 点击正文左上角“大纲”，再点击章节标题。 |

文件树没有及时显示变化时，可右键“刷新”。

## 05 打开代码文件

除了 Markdown 和 TXT，Arkdown 也能打开常见代码和配置文件，例如 `.json`、`.js`、`.cjs`、`.ts`、`.py`、`.html`、`.css`、`.yaml`、`.csv`、`.sql`、`.ps1` 等。

这些文件会直接进入源码模式，方便阅读和修改；Arkdown 不会运行其中的程序。

Word、PDF 等文档的打开方式，见[保存、转换与导出](<05-保存、转换与导出.md>)。
