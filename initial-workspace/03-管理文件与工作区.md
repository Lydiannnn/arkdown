# 管理文件与工作区

用熟悉的文件夹组织笔记，在文件树中浏览，在正文大纲中定位。

## 01 打开文档与文件夹

| 你的目的 | 操作 |
| --- | --- |
| 打开一篇文档 | 文件 → 打开文档…，或按 `Ctrl + O`。 |
| 打开工作区 | 文件 → 打开文件夹…，或按 `Ctrl + Shift + O`。 |
| 另开一个窗口 | 文件 → 新建窗口，或按 `Ctrl + Shift + N`。 |
| 继续最近的写作 | 文件 → 最近编辑的文档…。 |

也可以把文件或文件夹拖入窗口。将文件或文件夹拖入正文可插入路径链接；拖入文件夹时，也可按提示选择切换工作区。

## 02 新建、重命名与颜色标记

在工作区根部或空白处右键，可以“新建文档”“新建文件夹”或“刷新”。文档名称没有扩展名时会补上 `.md`。

右键某个文档或文件夹，可以在新窗口打开、打开所在文件夹、复制绝对路径、标记颜色、重命名或查看属性。文档还可“创建副本”。

**删除前看清对象**

“移到回收站”作用于实际文件或文件夹。它与隐藏侧栏、关闭窗口不同。请确认选中的对象后再操作。

## 03 浏览、大纲与搜索

| 方式 | 适合场景 |
| --- | --- |
| 文件 | 按文件夹层级浏览和定位文档。 |
| 大纲 | 点击正文左上角“大纲”，按当前文档的标题跳转，折叠不需要的层级。 |
| 工作区搜索 | 在左侧搜索入口输入关键词，点击“搜索”或按回车；需要搜索子目录时按提示继续。 |
| 在文档中搜索 | 按 `Ctrl + F`，只查找当前文档。 |

如果刚在资源管理器中添加或移动了文件，请先刷新工作区，再确认搜索目录是否正确。

## 04 哪些文件会被识别

**直接编辑：**`.md`、`.txt`\
`.markdown`、`.mmd`、`.mkd`、`.mdwn`、`.mdown`、`.mdx`、`.mdtxt`、`.mdtext`、`.apib`、`.rmarkdown`、`.rmd`、`.qmd`、`.text`

**Word 导入：**`.docx`

**转换为 Markdown：**`.pdf`、`.xlsx`、`.pptx`、`.epub`

**扩展名不等于完整语法支持**

例如 .mdx 可以作为文本文档打开，但并不表示会运行其中的组件或程序。

查看导入和转换步骤（参见：05-保存、转换与导出.md）
