# 保存、转换与导出

写完后按 `Ctrl + S`，让修改真正保存到文件。

## 01 保存与另存为

| 操作 | 用途 |
| --- | --- |
| `Ctrl + S` | 保存当前文档；新文档会先让你选择位置。 |
| `Ctrl + Shift + S` | 另存一份，保留不同版本或换个保存位置。 |

Arkdown 会自动备份临时草稿，但**临时草稿不等于原文件已保存**。准备分享文档或交给其他软件打开时，请先保存。便签则会在停止输入后自动保存。

## 02 关闭文档

有未保存修改时，关闭窗口会询问：

- **保存：**保存后关闭。
- **不保存：**放弃本次未保存的修改并关闭。
- **取消：**回到编辑器，继续保留当前内容。

在选择保存位置时取消，也会回到编辑器。遇到保存失败，先保留窗口，按提示处理，或另存到其他位置。

## 03 恢复草稿

启动时若提示有未结束的草稿，可以选择“恢复”查看。选择“暂不恢复”会保留草稿，不再自动提醒这些草稿。

之后可从“文件 → 查看保留的草稿”再次打开。恢复后，核对内容并按 `Ctrl + S` 保存。

重要文档仍建议另留副本，不要把临时草稿当作长期备份。

## 04 遇到保存冲突

保存冲突通常表示文件被其他窗口或程序修改过。先把当前内容另存一份，再比较两份文档，避免覆盖其他修改。

## 05 转换其他格式的文档

- **Word（DOCX）：**打开后转换成 Markdown。编辑后保存为 Markdown，不会改写原 Word 文件。
- **PDF、PPTX、XLSX、EPUB：**打开后查看转换预览，点击“新建 Markdown”，再保存新文档。

首次使用时，按提示下载所需组件。下载完成后可以重复使用；转换在本机完成，不会为转换上传原文档。

复杂版式、分页和图片可能无法完整保留，请保留原文件，核对转换结果。

## 06 导出与打印

| 想得到什么 | 操作 |
| --- | --- |
| Word 文档 | 文件 → 导出… → DOCX… |
| Excel 工作簿 | 文件 → 导出… → XLSX… |
| 打印或保存 PDF | 文件 → 打印…，或按 `Ctrl + P`；选择打印机或 PDF 打印机。 |

Word 导出中的 Mermaid 会保留为代码；需要图形时，请先在图形窗口保存图片。Excel 导出会整理文字和表格，不会保留整页外观。

文档中有本地图片时，分享方法见[图片与本地资源](<06-图片与本地资源.md>)。
