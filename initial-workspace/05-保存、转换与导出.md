# 保存、转换与导出

分清临时草稿、原文件和转换结果，让每次保存都有明确去处。

## 01 先分清三种保存

| 内容 | 何时写入 | 保存到哪里 |
| --- | --- | --- |
| 普通文档的临时草稿 | 编辑后自动备份 | 程序的 temp 临时草稿目录 |
| 普通文档原文件 | 按 Ctrl + S 或选择保存 | 原文件；新文档需先选择位置 |
| 便签 | 停止输入后实时保存 | 便签自己的存储目录 |

**“已备份到临时草稿”不等于原文件已更新**

想让其他软件读到这次修改，或者准备交付文件时，请先手动保存。

## 02 保存、另存与关闭

1. **保存当前文件**
   按 `Ctrl + S`。新文档会要求选择保存位置。
2. **保留另一份版本**
   按 `Ctrl + Shift + S` 使用“另存为…”，选择新的文件名。
3. **处理未保存提示**
   关闭或切换文档时如有未保存修改，按提示选择保存、不保存或取消。取消会让你返回当前操作。

保存失败时，先保留当前窗口。检查写入权限、磁盘空间，必要时另存到可写位置。

## 03 恢复草稿与处理冲突

异常退出后再次启动，如果出现“恢复未保存的内容”，先恢复并检查草稿，再手动保存到需要的位置。临时草稿不是长期备份，请另外保留重要文档副本。

**遇到保存冲突时**

这通常表示磁盘上的文件已被其他程序修改。不要急着覆盖。先把当前编辑内容另存一份，再比较磁盘版本与新副本，确认后合并。

Arkdown 会保留文件的 UTF-8 / UTF-8 BOM 编码形式和 LF / CRLF 换行形式。遇到其他编码的文档，请先用熟悉的文本工具确认编码。

## 04 把其他文档转成 Markdown

**DOCX：**打开 Word 文档后，Arkdown 会将其转换成 Markdown 编辑内容。源 DOCX 不会直接改写；编辑后保存为 Markdown。

1. **选择需要转换的文档**
   在工作区打开 PDF、PPTX、XLSX 或 EPUB，进入“转换文档预览”。
2. **按提示安装转换组件**
   首次使用需主动安装。当前组件由程序随附的本地归档提供，也可在偏好设置的“文档转换”中管理。
3. **检查预览，再创建文档**
   确认文字与结构后点击“新建 Markdown”。结果成为未保存的新草稿，最后按 Ctrl + S 选择位置。

**转换侧重内容提取**

原始分页、复杂版式和图片不保证保留。转换仅在本机读取来源文件，不上传或修改它；请保留原文件用于核对。

## 05 导出 DOCX、XLSX 或打印

| 目标 | 入口 | 需要了解 |
| --- | --- | --- |
| Word 文档 | 文件 → 导出... → DOCX... | 选择新的目标文件；Mermaid 保留源码，不转成图片。 |
| Excel 工作簿 | 文件 → 导出... → XLSX... | 将文字和表格输出为工作表内容，不是原页面的截图。 |
| 纸张或 PDF | 文件 → 打印… / Ctrl + P | 在 Windows 打印对话框中选择打印机；打印为 PDF 时选择对应的 PDF 打印机。 |

PDF 通过 Windows 打印完成。当前没有单独的 HTML 导出入口。
