AI 给了你一份验收记录、一张路线图，或一篇写到一半的方案。接下来，你需要读懂它、修改它，再把它变成真正能用的成果。

**Arkdown 就是为这样的时刻准备的。**

打开 Markdown，以接近日常文字处理软件的方式阅读和编辑；沿着文档中的链接查阅项目资料，让 AI 在侧窗帮你分析、整理与修改；把暂时放不下的重要信息，留在桌面便签上。

从 AI 的一份交付文档，到你自己的整套知识库，文件始终保存在本地，使用哪个模型也由你决定。

## 从阅读一份 Markdown 开始

Markdown 是 AI 经常使用的交付格式，也是很适合长期保存的文字格式。Arkdown 希望让它更自然地进入日常工作。

标题成为清晰的大纲，待办事项成为可以勾选的任务列表，引用、表格和代码块各有合适的呈现。你可以直接在渲染后的文档中修改内容，也可以随时切换到源码模式，查看 Markdown 的原始表达。

- **阅读与编辑：** 大纲、查找、列表、任务、表格与引用，覆盖常见的文档整理需求。
- **图文与附件：** 插入图片、音视频和本地文件链接，让文字与相关资料放在一起。
- **Mermaid 图表：** 在正文中查看流程图，点击图形后用独立窗口放大阅读，支持缩放、平移和保存为图片。
- **代码文档：** 打开 JSON、JavaScript、TypeScript、CJS 等常见文本代码文件，默认进入源码模式。

读一份技术说明、修改会议纪要，或者整理 AI 给出的计划，都可以从同一处开始。

## 一个文件夹，就是一个工作区

把项目资料、读书笔记或工作记录放进文件夹，用 Arkdown 打开。左侧的文件树与搜索，帮助你在这些文档之间来回查阅。

尤其是 AI Agent 生成的项目资料：一份验收报告会引用试用清单，一份清单又指向阶段记录和配置文件。Arkdown 让这些引用有了顺手的阅读方式。

**按住 Ctrl 并单击正文中的相对文档链接，可以在右侧“文档查看”窗格中只读预览。** 主文档留在原处，相关的 Markdown、TXT 或代码内容在侧边展开。需要进一步编辑时，再用新窗口打开；在侧窗中继续打开支持的本地相对文档链接，也会交给新窗口。

本地文件链接还支持右键“打开文件位置”，直接定位到资源管理器中的目标文件。工作区文件行上的“拖出文件”按钮，则可以把磁盘上已保存的文件复制到桌面或其他文件夹。

### 让不同格式的资料进入同一套工作流

| 手边的资料 | 在 Arkdown 中使用 |
| --- | --- |
| Markdown、TXT | 直接打开、阅读与编辑。 |
| JSON、JS、TS、CJS 等代码文件 | 在源码模式中查看和编辑，也可通过相对链接在侧窗预览。 |
| DOCX | 导入为 Markdown 继续编辑，也支持导出 DOCX。 |
| PDF、PPTX、XLSX、EPUB | 通过本地组件提取内容，预览确认后生成 Markdown 草稿。 |
| 图片、音频、视频及其他附件 | 作为文档中的本地资源或链接使用。 |

格式转换侧重文字与结构的提取，不保证复原复杂分页和原始版式。转换后的内容可以继续整理，原文件请保留。

## 让 AI 和你一起处理文档

当资料已经在手边，AI 最有用的地方，是帮助你继续完成眼前的工作。

通过自己的 API Key 连接支持的模型服务，或选择 Codex CLI 并完成登录，你就可以在侧窗中与 AI 对话。按需允许它读取当前文档、查找工作区资料，并依照写入许可帮助你修改内容。

选中一段文字引用到对话中，把问题说得更具体。

例如，你可以这样开始：

> 总结这份验收记录，把已经通过、仍需处理和需要我确认的事项分别列出来。

> 查找工作区中与登录流程有关的文档，对比其中的要求是否一致。先给出结论，不修改文件。

> 只修改“下一步计划”这一节，把每项工作写清楚，其余内容保持不变。

处理过程中，可以查看模型服务提供的思考内容或摘要、工具操作和执行结果。任务达到本段操作额度时，Arkdown 会说明哪些已完成、哪些尚未执行，你可以核对后继续。

**模型由你选择，服务费用按相应提供方的规则结算。** Arkdown 本身免费，不额外要求购买 Arkdown 的 AI 订阅。

AI 改文目前采用整篇写回，可能影响要求范围之外的内容。重要文档先留副本，修改后检查结果；已经打开的文档仍需保存，未打开的工作区文档可能直接写入磁盘。

### 代码解释，让技术文档更容易读懂

方案中的一段脚本、验收记录里的示例代码，或 AI 给出的配置片段，未必一眼就能看懂。

从文档中的代码块发起 AI 对话，就能一键生成代码说明。你可以继续追问这段代码的用途、执行步骤、输入输出，以及某个参数会怎样影响结果，让 AI 把代码与当前文档中的问题联系起来解释。

例如：“用容易理解的方式解释这段代码，说明各个步骤在做什么，先不要修改。”读懂之后，再决定是否需要调整。

## 阅读时，少被语言打断

读英文资料、查阅技术说明时，翻译应当就在手边。选中文档中的文字，通过划词翻译在侧窗查看译文，继续对照原文阅读。

你可以选择翻译模型与目标语言。使用云端翻译模型时，待翻译的内容会发送给你配置的服务。

## 把重要的小事，留在桌面上

文档适合收纳完整的思路，便签适合放下此刻不能忘记的事情。

Arkdown 配套独立桌面便签 **Arknote**。选中正文中的内容，就能建立便签：一小段待办、一句需要反复看的提醒，或会议结束后留下的几个重点，都可以留在视线里。

便签支持列表、任务、双击标题重命名和多种外观，可以通过便签盒子与托盘管理。你还可以选择是否在任务栏显示活跃便签。

Arknote 可以独立运行。关闭 Arkdown 后，便签仍可以陪着你完成接下来的工作。

## 让每天打开的窗口，好看一点

文档工具会陪伴我们很长时间。文字是否舒展、颜色是否舒服、窗口是否与桌面协调，都是使用体验的一部分。

Arkdown 提供浅色、深色和跟随系统主题，也可以设置自己的背景。侧边栏与便签融入 Mica 视觉效果；便签另外提供 Acrylic、暖雾玻璃与深色玻璃材质，让不同的信息拥有合适的外观。

你可以给专注阅读留一块安静的背景，也可以让桌面上的几张便签，成为自己喜欢的样子。

## 常见问题

### 文档会上传到云端吗？

文档以本地文件保存，日常编辑与本地格式转换不依赖云端文档存储。使用云端 AI 或翻译时，相关输入、获得读取许可的文档内容及工具结果会发送给所选服务；具体处理方式取决于该服务的数据政策。

### 不使用 AI，也能正常使用吗？

可以。Arkdown 的文档编辑、工作区、源码查看和桌面便签都可以独立使用。需要 AI 时再配置模型即可。

### 会自动保存对文档的修改吗？

编辑中的内容会保留临时草稿，但草稿备份不等于写回原文件。请使用保存操作确认修改；关闭文档时，可以选择保存、不保存或取消。AI 对未打开工作区文档的修改可能直接写入磁盘。

### 可以替代代码编辑器吗？

Arkdown 适合在阅读和写作时顺手查看、修改代码或配置文件，也可以用 AI 理解代码。它的重点仍然是文档工作，不提供完整 IDE 的开发与调试环境。

### 目前有 macOS 版本吗？

当前发布的是 Windows 版本，macOS 版尚未发布。

## 关于这个项目

Arkdown 起于一个很具体的想法：做一款符合自己使用习惯的笔记工具，再做一个愿意长期留在桌面上的便签软件。

随着与 AI 一起工作的时间越来越多，我也希望它能承接那些不断产生的 Markdown 文档：让它们容易阅读、方便修改，能够被整理成自己的资料，而不只是留在聊天记录里的附件。

我会继续维护 Arkdown，改进日常使用中那些细小却重要的体验。欢迎通过 Issue 反馈问题与建议，也欢迎通过 Pull Request 参与代码和文档改进。报告问题时，附上版本、复现步骤，以及不含隐私信息的示例，会更方便定位。

如果 Arkdown 让你的工作顺手了一点，欢迎留下一个 Star。感谢你愿意下载、使用，并一起把它变得更好。
