CHAPTER 01 使用指南

把想法写下来

Arkdown 是一个本地文档工作区。你可以用它写笔记、整理文件、请 AI 协助改文，也可以把零散想法留在桌面便签上。

先试着编辑这篇文档，熟悉后再选择自己的文件夹开始使用。

4 个小节·更新于 2026-10-13
01

今天的计划

#
  • 收集参考资料
  • 整理文章大纲
  • 写下第一版内容
02

留住值得记下的事

#

先记录，再整理。 用标题划分内容，用列表列出行动。

写作是一件可以慢慢来的事。

03

从这里开始

#
想做什么怎么开始
整理自己的文档点击左上角工作区按钮，选择一个文件夹。
写一篇新文档按 Ctrl + N，写完后按 Ctrl + S 保存。
请 AI 协助处理文档在偏好设置中连接大模型，再打开右侧“AI 对话”。
留下一张桌面便签打开右上角“便签盒子”，或选中正文后右键“建立便签”。

点击这里选择工作区，或者新建文档。在 Arkdown 正文中打开链接，请按住 Ctrl 再单击。

04

按需要阅读

#
  • 与 AI 一起处理文档：连接模型、提问和修改文档。
  • 管理文件与工作区：打开、整理和查找文件。
  • 编辑与排版：标题、列表、表格和流程图。
  • 保存、转换与导出：保存文件、恢复草稿和转换格式。
  • 图片与本地资源：插入图片、媒体和文件链接。
  • 用便签收纳零散想法：创建、改名和整理便签。
  • 划词翻译与截图识别：翻译文字和提取屏幕上的文字。
  • 把 Arkdown 调整得顺手：字体、背景、默认程序和组件。
  • 常用快捷键：常用操作速查。

写完后记得按 Ctrl + S。自动备份的临时草稿不能代替保存。
