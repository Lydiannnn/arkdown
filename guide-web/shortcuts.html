常用快捷键

把高频操作留在手边。以下为 Windows 版 Arkdown 的默认快捷键；自定义后以“编辑 → 快捷键”中的设置为准。

自定义快捷键

打开“编辑 → 快捷键”，点击“修改”后按下组合键，修改后立即保存。支持清除和恢复默认；通用编辑、格式与导航键固定显示。按 Esc 取消录入。

快捷键的作用取决于当前窗口

例如便签盒子中的 Ctrl + F 搜索便签；文档编辑器中的 Ctrl + F 查找当前文档。本说明网页的搜索可按 Ctrl + K 打开。
