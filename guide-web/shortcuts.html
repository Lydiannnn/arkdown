常用快捷键

以下为 Windows 版 Arkdown 的默认快捷键。自定义后，以“编辑 → 快捷键”中的设置为准。

5 个小节·更新于 2026-10-13
01

文件与窗口

#
操作快捷键
新建文档Ctrl + N
新建窗口Ctrl + Shift + N
打开文档Ctrl + O
打开文件夹Ctrl + Shift + O
保存Ctrl + S
另存为Ctrl + Shift + S
打印Ctrl + P
关闭窗口Ctrl + W

04

翻译工具

#
操作快捷键
截图翻译Ctrl + Shift + Q

悬浮翻译的快捷键仅在该工具打开时生效；入口为“工具 → 悬浮翻译窗（实验功能）”。

05

修改快捷键

#

打开“编辑 → 快捷键”，点击“修改”后按下新的组合键。按 Esc 取消，也可以按界面提示恢复默认。

先点击要操作的区域，再使用快捷键。例如，在便签盒子按 Ctrl + F 搜索便签；在正文中按它，则搜索当前文档。
