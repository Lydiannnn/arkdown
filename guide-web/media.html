CHAPTER 05 扩展你的笔记

图片与本地资源

把图像、音频、视频和文件链接放进笔记，同时了解它们实际存放的位置。

3 个小节·更新于 2026-09-29
01

将资源拖入正文

#

将支持的本地资源拖到正文中的目标位置。图片显示为图片引用，音频和视频使用媒体元素，PDF 和 XLSX 可以作为文件链接插入。

图片：.png、.jpg、.jpeg、.gif、.webp、.avif、.bmp、.svg

音频：.mp3、.wav、.ogg、.m4a、.aac、.flac

视频：.mp4、.webm、.ogv、.mov、.m4v

文件扩展名受支持，不保证所有编码都能播放

如果音频或视频不能预览，先用系统播放器检查文件是否正常、编码是否受当前运行环境支持。

02

理解本地引用

#

拖入本地文件时，资源保留原位置，文档记录其绝对路径。移动或删除源资源会导致预览和链接失效。

从剪贴板粘贴图片时，Arkdown 会先暂存图片；保存文档时，将这些图片放入文档旁的 assets 文件夹，并写入相对引用。迁移这类文档时，请带上对应的 assets 文件夹。

图片右键中的另存或复制到新位置只会创建副本，不会移动、重命名、删除或覆盖原资源。新建副本后，如果要改用新位置，还需要更新正文引用。

准备迁移或分享笔记

请同时检查正文里的资源路径。不要只复制 Markdown 文件就认为图片已经包含在内。便签导入本地资源的复制规则请见便签章节。

03

打开链接与定位文件

#

按住 Ctrl 再点击正文中的 PDF 链接，Windows 会用默认 PDF 程序打开它。文件已被移动或删除时，请修正链接地址或重新插入资源。

需要查看实际文件时，可使用链接或图片对应的右键菜单。不要把“移除文档引用”与“删除磁盘文件”混为一谈。
