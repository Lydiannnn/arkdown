CHAPTER 02 写作与整理

管理文件与工作区

用熟悉的文件夹组织笔记，在文件树中浏览，在正文大纲中定位。

5 个小节·更新于 2026-09-29
01

打开文档与文件夹

#
你的目的操作
打开一篇文档文件 → 打开文档…，或按 Ctrl + O。
打开工作区文件 → 打开文件夹…，或按 Ctrl + Shift + O。
另开一个窗口文件 → 新建窗口，或按 Ctrl + Shift + N。
继续最近的写作文件 → 最近编辑的文档…。

也可以把文件或文件夹拖入窗口。将文件或文件夹拖入正文可插入路径链接；拖入文件夹时，也可按提示选择切换工作区。

02

新建、重命名与颜色标记

#

在工作区根部或空白处右键，可以“新建文档”“新建文件夹”或“刷新”。文档名称没有扩展名时会补上 .md。

右键某个文档或文件夹，可以在新窗口打开、打开所在文件夹、复制绝对路径、标记颜色、重命名或查看属性。文档还可“创建副本”。

删除前看清对象

“移到回收站”作用于实际文件或文件夹。它与隐藏侧栏、关闭窗口不同。请确认选中的对象后再操作。

03

浏览、大纲与搜索

#
方式适合场景
文件按文件夹层级浏览和定位文档。
大纲点击正文左上角“大纲”，按当前文档的标题跳转，折叠不需要的层级。
工作区搜索在左侧搜索入口输入关键词，点击“搜索”或按回车；需要搜索子目录时按提示继续。
在文档中搜索按 Ctrl + F，只查找当前文档。

如果刚在资源管理器中添加或移动了文件，请先刷新工作区，再确认搜索目录是否正确。

04

用文档查看追踪相对链接

#

按住 Ctrl 单击正文中的相对链接，例如 ./reports/result.md 或 ../data/result.json，在右侧“文档查看”打开目标。相对链接用浅蓝色区分；普通单击仍用于编辑，绝对路径和网页链接沿用原有打开方式。

Markdown 显示排版，TXT 显示原文，代码显示源码与行号。面包屑记录当前阅读路径；右键面包屑选择“使用新窗口打开”可编辑该文件。返回原文档时保留未保存内容；侧窗中的任务列表不可勾选。

侧窗中的相对文件链接使用 Ctrl＋单击在新窗口打开；已经打开的文档会聚焦已有窗口。侧窗保留当前内容和阅读位置，纯章节链接仍在侧窗内跳转。正文右键提供“复制”和“在新窗口打开该文档”；未选中文字时“复制”禁用。

侧窗支持独立查找、选择和复制。外部修改会显示刷新提示；点击刷新才替换预览。相对路径按链接所在文档的目录解析，因此转交报告时也需保留其引用文件与目录结构。

05

哪些文件会被识别

#

直接编辑：.md、.txt
.js、.mjs、.cjs、.jsx、.ts、.tsx、.mts、.cts、.json、.jsonc、.json5、.yaml、.yml、.toml、.ini、.conf、.cfg、.properties、.xml、.html、.htm、.css、.scss、.sass、.less、.vue、.svelte、.astro、.py、.pyi、.r、.sql、.c、.h、.cc、.cpp、.cxx、.hpp、.cs、.java、.kt、.kts、.go、.rs、.swift、.dart、.rb、.php、.lua、.sh、.bash、.zsh、.fish、.ps1、.psm1、.psd1、.bat、.cmd、.cmake、.csv、.tsv、.log、.diff、.patch、.graphql、.gql、.proto、.tex、.markdown、.mmd、.mkd、.mdwn、.mdown、.mdx、.mdtxt、.mdtext、.apib、.rmarkdown、.rmd、.qmd、.text

Word 导入：.docx

转换为 Markdown：.pdf、.xlsx、.pptx、.epub

代码文档默认进入源码模式，保留原始文本，不执行代码或注册系统文件关联。也支持 Dockerfile、Makefile、CMakeLists.txt、.gitignore、.gitattributes、.editorconfig、.env 和 .env.*；SVG 通过“打开文档”可编辑源码，拖入正文仍作为图片。代码文档和文档查看限 UTF-8 / UTF-8 BOM、8 MiB 以内。

扩展名不等于完整语法支持

例如 .mdx 可以作为文本文档打开，但并不表示会运行其中的组件或程序。
