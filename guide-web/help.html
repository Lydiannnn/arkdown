CHAPTER 11 查阅与帮助

遇到问题，从这里查

先确认现象，再按步骤检查。保存相关的问题优先保护当前内容。

5 个小节·更新于 2026-09-29
01

修改好像没有保存

#
  1. 检查状态

    “已备份到临时草稿”只说明存在恢复副本。按 Ctrl + S，等待保存完成。

  2. 确认文件位置

    检查正在编辑和在其他软件中查看的是否为同一个文件。新文档和转换草稿需先选择保存位置。

  3. 若出现失败或冲突

    先另存一份当前内容，再检查权限、磁盘空间或外部修改。

02

文件、图片或链接不见了

#
  1. 文件树没有文档

    确认打开的文件夹正确，刷新工作区，并检查扩展名是否受支持。

  2. 图片不显示

    检查资源是否被移动或删除，以及引用是否仍指向原位置。

  3. PDF 不能打开

    按住 Ctrl 再点击链接；检查文件存在，并确认 Windows 已设置可用的 PDF 默认程序。

03

转换或翻译无法完成

#

转换文档失败：确认转换组件已安装，文件未损坏、未被移动，并重新选择来源文件。结果版式不同不一定是失败；转换主要提取文字和结构。

翻译失败：先检查是否为对应功能分配模型，再查看认证、接口地址、模型 ID、网络和服务商额度。截图识别失败时，缩小截图范围或提高文字清晰度。

查看模型连接状态说明 →

04

移动程序与备份

#

请保持程序随附文件完整。设置优先保存在程序旁的 portable-data，临时草稿保存在 temp；具体写入还取决于所在目录是否可写。

备份时，保留自己的文档文件夹、文档引用的资源，以及需要保留的程序数据。移动后重新检查便签开机启动设置与本地资源路径。

临时草稿不能代替长期备份

重要文件请另存到独立备份位置。不要在有待恢复内容时随意清理 temp。

05

当前的功能边界

#
  • 当前面向 Windows；没有安装器和自动更新。
  • 当前编辑器提供“简约”主题、主题颜色与背景设置；没有专注模式、打字机模式。
  • 支持 DOCX、XLSX 导出；PDF 走 Windows 打印，没有独立 HTML 导出入口。
  • AI 对话、划词翻译、截图翻译需要分别配置使用模型。
  • 本地编辑、图表渲染与文档转换不依赖模型服务；调用远程模型和下载 OCR 模型需要网络。

本说明依据当前 Arkdown 0.1.0 的功能与界面编写，更新于 2026-09-07。
