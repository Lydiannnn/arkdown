划词翻译与截图识别

为文字配置翻译模型，也可以从屏幕截取内容，在本机识别文字后再翻译。

4 个小节·更新于 2026-09-29
01

先配置使用的模型

#
  1. 进入大模型设置

    文件 → 偏好设置 → 大模型设置，点击“管理大模型”。

  2. 添加并连接模型

    按服务商提供的信息填写接口地址、模型 ID 和 API Key，选择匹配的协议，再执行连接。连接操作会保存并测试配置。

  3. 分配给翻译功能

    分别设置“划词翻译配置”和“截图翻译配置”的使用模型、目标语言与推理强度。修改会即时保存，完成后关闭设置。

翻译会访问配置的模型服务

本地编辑不需要联网；调用翻译时，相关文字会发送给你配置的模型服务。是否收费及可用额度由服务商决定。

02

选中文字，发起翻译

#

选中需要翻译的正文，点击出现的翻译入口。结果可以在翻译浮层或右侧栏查看，并可复制。需要查阅以前的结果时，打开“翻译记录”。

翻译过程中可停止；失败时可重试。出现“尚未配置划词翻译使用的大模型”时，请回到模型管理页，确认已经为划词翻译分配模型。

原文仍由你决定

查看和复制译文不会自动把译文写进原文。需要替换时，请自行检查后编辑并保存文档。

03

截取屏幕并识别文字

#
  1. 开始截图

    选择“工具 → 截图翻译”，或按 Ctrl + Shift + Q。

  2. 框选需要的区域

    选择文字所在区域，等待文字识别完成。

  3. 查看识别与译文

    在截图翻译窗口检查内容，按界面入口翻译或重新翻译。

截图和文字识别在本机进行；翻译只将识别出的文字发送给指定模型。未配置模型时，截图和提取文字仍可在本机使用。

识别效果不理想

尽量截取清晰、字号较大的文字。在“截图OCR识别”设置中，可按需下载 PP-OCRv6 Medium 模型以提升识别效果。模型下载需要网络。

04

连接失败时检查什么

#
状态下一步
认证失败检查 API Key 是否正确、有效。
模型不存在 / 接口地址无效核对模型 ID、接口地址及兼容协议。
请求超时 / 服务商限流检查连接状态，稍后再试，避免连续重复提交。
余额或配额不足到所用服务商检查余额和可用额度。

AI 对话另有独立的模型配置；翻译配置不能替代 AI 对话配置。
