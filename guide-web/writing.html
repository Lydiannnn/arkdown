CHAPTER 03 写作与整理

编辑与排版

从标题和列表到表格与流程图，用 Markdown 把内容表达清楚。

5 个小节·更新于 2026-09-29
01

在两种编辑模式间切换

#

即时渲染模式直接呈现标题、列表、引用等排版效果，适合日常写作。源码模式显示完整 Markdown 标记，适合调整缩进、链接和代码。

点击工具栏“源码模式/渲染模式”，或按 Ctrl + / 切换。

撤销历史按模式分别记录

切换后会建立当前模式的撤销历史。Ctrl + Z 不会跨模式回到切换前的编辑步骤。

02

常用格式，一边写一边用

#
内容Markdown 示例菜单或快捷键
一级标题# 标题段落 → 一级标题 / Ctrl + 1
加粗**重点**格式 → 加粗 / Ctrl + B
斜体*强调*格式 → 斜体 / Ctrl + I
链接[文字](地址)格式 → 链接… / Ctrl + K
任务列表- [ ] 待办事项段落 → 任务列表
引用> 引用内容段落 → 引用

引用、代码块和列表按钮会显示当前位置的状态；再次点击已启用的结构按钮，可取消相应结构。

03

右键菜单会随对象变化

#
  • 选中文字：剪切、复制、格式设置、建立便签，以及主动使用默认浏览器搜索。
  • 链接：打开、复制或编辑地址，也可移除文档中的链接。
  • 图片：调整显示、替代文本，复制或另存副本，移除图片引用。
  • 表格：插入或删除行列、调整对齐、移动、复制和格式化。
  • 源码模式：搜索、撤销、剪贴板、格式操作与整行移动。

代码块和任务列表使用文本与结构菜单。图片的删除操作移除的是正文中的引用；复制或另存只建立副本。

04

用 Mermaid 写流程图

#
MERMAID · 流程图示例
```mermaid
flowchart LR
  A[收集资料] --> B[整理笔记]
  B --> C[完成初稿]
```

在即时渲染模式查看图形；使用图表工具栏的“编辑源码”和“显示图形”往返切换。保存的始终是 Mermaid 源码，生成的图形不会替代文档文本。图形渲染无需联网。

单击已经生成的 Mermaid 图像，可在独立窗口查看当前图形快照。初始按最小可见文字 14 CSS 像素选择阅读比例；大图可拖动平移、滚轮缩放，也可使用“适合窗口”“阅读大小”和放大、缩小按钮。按 Esc 关闭查看窗口，不会修改文档。

图形没有出现

先检查 Mermaid 语法。单块最多 20,000 字符和 100 条边，每个编辑器最多 30 个图块；单次生成预算为 2.5 秒，过于复杂时请拆分图表。

打印时会等待图形准备完成。DOCX 导出保留 Mermaid 源码块，不会自动嵌入流程图图片。

05

调整阅读空间

#

“视图”菜单提供侧栏开关、源码编辑提示、编辑区缩放、整体缩放和全屏。“源码编辑提示”仅控制源码模式的行变更标记，在即时渲染模式也可切换此开关；即时渲染模式不显示编辑提示。仅调整编辑区大小时，菜单和侧栏大小保持不变。

编辑区缩放范围为 70%～200%，可用“恢复编辑区大小”回到 100%。字体、正文宽度和最小边距则在偏好设置中调整。
